This is the standard Confluence page format for all TechnoAI-26 (Tech Fair 2026) submissions at Aristocrat.

**Required sections in order:**
1. **Header line:** "Use this page to capture a complete, reusable summary of your Tech Fair-26 idea or solution. Keep it clear enough for presentation and detailed enough for future team reference."
2. **Solution Overview** — bold metadata fields: Idea/Solution Name, Team Name, Contributors, Summary
3. **Problem Statement** — narrative + bullet list of pain points with bold labels
4. **Business Value** — bullet list with bold label + colon format (e.g., "Time savings:", "Error reduction / quality:")
5. **Target Audience** — bold "Audience:" label + description
6. **Solution Details** — numbered steps describing the user flow
7. **Technical Details** — narrative paragraph, then sub-sections:
   - **Architecture / Design** — bullet list with bold labels
   - **Technology Stack** — bullet list (languages, infra, tools)
   - **Integrations / Dependencies** — bullet list
8. **Demo and Supporting Material** — bold labels: Demo Link, Repository / Code Link, Designs / Documents, Screenshots or Attachments
9. **Future Potential** — bullet list or freeform description of next steps/enhancements

**Reference example:** Paltronics Rev8 (T2E) setup automation tool by team "Click2Config" (Govinda Kumar, Siddharth Pandey, Anchal Nerurkar, Sameen Ashraf) — used as format reference.

**How to apply:** When user says "create a Confluence page" or "create a TechnoAI page" for a tool, use this exact section order. Use the PDF as visual reference for typography/layout if rendering as HTML.
